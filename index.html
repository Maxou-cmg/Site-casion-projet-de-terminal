Publier en ligne en 3 étapes

Le site est prêt à être envoyé sur un hébergeur statique. La méthode la plus simple consiste à utiliser GitHub Pages, car le dépôt contient déjà la page principale.

  1. Ouvrez votre dépôt GitHub.
  2. Allez dans Settings → Pages.
  3. Sélectionnez la branche main et validez.
Astuce : si vous voulez une mise en ligne encore plus rapide, utilisez Netlify ou Vercel avec ce même dossier.
